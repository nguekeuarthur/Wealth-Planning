# Configuration des Variables d'Environnement

## 📁 Où créer le fichier .env

Le fichier `.env` doit être créé à la racine du projet :
```
/Users/edimaevinawilfriedbryan/Desktop/PROJET - WEALTH PLANNING/Wealth-Planning/.env
```

## 📋 Variables à configurer

Copiez le contenu ci-dessous dans votre fichier `.env` et remplacez les valeurs par les vôtres :

```env
# Configuration de base
NODE_ENV=development
PORT=8000

# Base de données MongoDB
MONGODB_URI=mongodb://localhost:27017/wealth-planning
# Pour MongoDB Atlas, utilisez quelque chose comme :
# MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/wealth-planning

# JWT Configuration
JWT_SECRET=votre-cle-secrete-très-longue-et-complexe-ici
JWT_ACCESS_EXPIRES=15m
JWT_REFRESH_EXPIRES_DAYS=7

# Configuration SMTP pour les emails (OBLIGATOIRE pour l'envoi d'emails)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=votre-email@gmail.com
SMTP_PASS=votre-mot-de-passe-application
EMAIL_FROM=votre-email@gmail.com

# URL du frontend (pour les liens de vérification d'email)
FRONTEND_URL=http://localhost:5173
CLIENT_URL=http://localhost:5173

# Tokens d'administration (pour créer le premier admin)
ADMIN_INVITE_TOKEN=votre-token-admin-unique

# Configuration des mots de passe
PASSWORD_RESET_TOKEN_MINUTES=15
EMAIL_VERIFICATION_EXPIRES_HOURS=24
MAX_LOGIN_ATTEMPTS=5
LOGIN_LOCK_DURATION_MIN=5

# Configuration des uploads (optionnel)
MAX_FILE_SIZE=10485760
UPLOAD_DIR=uploads/

# Configuration des logs (optionnel)
LOG_LEVEL=info

# Email de l'administrateur pour les notifications de rendez-vous
ADMIN_EMAIL=contact@genevawealth.com
```

## 🔑 Configuration Gmail SMTP

Pour configurer Gmail :

1. **Activer la vérification en deux étapes** sur votre compte Gmail
2. **Générer un mot de passe d'application** :
   - Allez dans les paramètres de sécurité de votre compte Google
   - Cliquez sur "Vérification en deux étapes"
   - En bas, cliquez sur "Mots de passe d'application"
   - Sélectionnez "Autre" et donnez un nom (ex: "Wealth Planning")
   - Copiez le mot de passe généré (16 caractères sans espaces)

3. **Variables SMTP** :
   ```
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_USER=votre-email@gmail.com
   SMTP_PASS=le-mot-de-passe-application-généré
   EMAIL_FROM=votre-email@gmail.com
   ```

## ⚠️ Variables critiques

**Sans ces variables configurées, les emails ne fonctionneront pas :**
- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_USER`
- `SMTP_PASS`
- `EMAIL_FROM`
- `FRONTEND_URL`

## 🔐 Sécurité

- Ne partagez jamais votre fichier `.env`
- Le fichier `.env` est automatiquement ignoré par Git
- Utilisez des mots de passe forts pour `JWT_SECRET`

## 🚀 Après configuration

Redémarrez votre serveur backend après avoir modifié le `.env` :
```bash
cd backend
npm start
```
